# Filo v0.1.0-preview.1

Release draft — not published yet.

Welcome to Filo, an Android learning app bringing classes, materials, and AI-assisted study together.

## This preview

- Intended for project testing on Android 8.0 and newer.
- Connects to the development (DEV) backend, not a production school deployment.
- Includes the current work on classes, files, classwork, assessments, and study tools. Availability and reliability still need owner verification in this exact APK.

## Download and install

When this release is published, download **Filo-v0.1.0-preview.1.apk** from **Assets**. The source-code ZIP and TAR.GZ files are not installers.

Open the APK on your Android device and follow Android's installation prompts. Sign in using the in-app flow.

## Before using this preview

- This is an early testing build. Do not use it as the only copy of important classwork.
- Internet is required for sign-in, synchronization, AI generation, submissions, and official assessments.
- AI answers can be incorrect; check source materials and your instructor's guidance.
- If an older development install uses a different signing key, Android may reject an in-place update. Do not uninstall before preserving local files and unsynced work.

## Feedback

Report issues with your Filo version, Android version, reproduction steps, and expected result. Redact personal information; never include passwords, verification codes, credentials, or private class files.

Signing passwords, GitHub authentication, exact source revision, signed APK packaging and owner install/sign-in checks are still pending. This draft does not attest that an APK was built, tested or uploaded.
